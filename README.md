An interactive, high-tech Security Operations Center (SOC) dashboard built with vanilla JavaScript and Tailwind CSS. Designed with a dark glassmorphic cyberpunk theme, **Aegis-X** provides real-time threat detection logs, interactive incident response tools, and network diagnostics simulations.

---

## ✨ Features

- 🖥️ **Interactive Terminal (CLI Console):** Executable SOC command line with dynamic logs (`status`, `isolate`, `lockdown`, `clear`, `help`).
- 🛠️ **Tactical Cyber Toolkit:**
  - **Port Scanner & IP Inspector:** Simulates network vulnerability scans.
  - **Hash Generator:** Instant cryptographic hashing (MD5/SHA256 simulation).
  - **Phishing Analyzer:** Heuristic pattern checker for suspicious URLs.
- 🚨 **Incident Management Center:** Add, investigate, and mitigate cyber security threats in real time.
- 💾 **Local Data Persistence:** Incidents and system states are automatically saved using `localStorage`.
- 🔊 **Web Audio Sound Effects:** Realistic cyber audio feedback for critical alerts and console actions.
- 🎨 **Modern Cyberpunk UI:** Custom glassmorphism layout, glow effects, and futuristic Orbitron typography.
